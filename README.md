# BullsAndBats

Unreal Engine 5.5와 C++로 만든 멀티플레이 숫자 야구 게임입니다.
CH4 숫자 야구 과제로, 강의의 채팅 기능을 바탕으로 숫자 판정과 기회 제한, 승리·무승부 처리, 게임 리셋을 구현했습니다.

## 게임 방법

하단 입력창에 채팅이나 숫자를 입력하고 Enter를 누릅니다.

- 정답은 1~9 사이의 중복 없는 세 자리 숫자입니다.
- 플레이어마다 3번의 기회가 있습니다. 잘못된 형식의 입력은 기회를 사용하지 않습니다.
- 숫자와 자리가 모두 같으면 Strike, 숫자는 같지만 자리가 다르면 Ball입니다. 맞는 숫자가 없으면 OUT입니다.
- 먼저 정답을 맞힌 사람이 승리합니다. 모두 기회를 쓰고도 맞히지 못하면 무승부입니다.
- 게임이 끝나면 결과를 화면에 남겨두고, 정답과 횟수를 초기화해 바로 새 게임을 시작합니다.

채팅과 판정 결과는 화면 왼쪽 위에 디버그 메시지로 10초 동안 표시됩니다. 판정 결과는 `Player1 (1/3): 123 -> 0S 1B` 형식이며, 괄호 안은 `(사용한 횟수/최대 횟수)`입니다.

## 실행 환경

개발 환경: Windows / Unreal Engine 5.5 / Visual Studio 2022

실행 맵: `Content/BullsAndBats/Maps/Chatting`

| 설정 | 값 |
| --- | --- |
| Play Net Mode | Play As Client |
| Number of Players | 2 |
| Run Under One Process | 해제 |
| Launch Separate Server | 체크 |

정답은 별도로 열린 서버 콘솔 창의 `[정답 확인]` 로그에서 볼 수 있습니다.

## 구현 과정

채팅 연결 후 정답 판정, 기회 관리, 결과 공지 순서로 구현했습니다.

### 1. 채팅 연결

위젯 입력을 PlayerController의 Server RPC로 보내고, 서버 GameMode에서 처리한 메시지를 각 PlayerController의 Client RPC로 전달합니다.

### 2. 정답 생성과 입력 검사

정답 생성과 Strike·Ball 판정은 강의 방식을 따랐습니다. 정답은 1~9 중 무작위로 뽑고, 선택한 숫자를 후보에서 제거해 중복을 막습니다. 판정은 같은 자리의 숫자를 먼저 비교하고, 자리가 다르면 정답에 포함된 숫자인지 확인합니다.

입력 검사는 원문 전체를 대상으로 길이가 정확히 세 자리인지 확인합니다. `TSet`에 숫자를 추가하기 전에 중복 여부도 확인해 `112` 같은 입력은 추측으로 처리하지 않습니다.

잘못된 입력은 기회를 소모하지 않으며, 길이·숫자 범위·중복에 따라 안내를 나눴습니다. `1a2` 같은 세 글자 혼합 입력도 안내 대상으로 추가했습니다.

### 3. 플레이어별 기회 관리

횟수는 PlayerState에 저장하고 서버에서 변경합니다. 증가 함수에서 남은 기회를 검사해 3회를 넘는 추측을 차단했습니다.

이름과 횟수가 포함된 문구는 서버에서 횟수를 증가시킨 뒤 만들어 첫 추측부터 `1/3`으로 표시합니다. 세 번째 실패 직후에는 해당 플레이어에게 기회 소진을 안내합니다.

### 4. 결과 공지와 리셋

승리·무승부 결과는 별도 공지 위젯에 표시합니다. 게임이 끝나면 정답을 새로 만들고, 모든 플레이어의 시도 횟수를 0으로 초기화합니다.

현재 시도 횟수는 프로퍼티 복제로 동기화합니다. 화면에 표시할 횟수와 판정 결과는 서버에서 문자열로 만들어 Client RPC로 보내고, 공지 위젯의 문구는 프로퍼티 복제로 전달합니다.

종료 판정과 리셋 호출은 각각 메시지·공지 전송 반복문이 끝난 뒤 실행합니다. 여러 플레이어에게 결과를 보내더라도 종료 판정과 정답 재생성은 한 번만 실행됩니다. 결과 문구에 새 게임 시작 안내를 함께 남겨 리셋 직후에도 결과를 볼 수 있게 했습니다.

## 입력 처리

| 입력 | 처리 |
| --- | --- |
| `123` | 기회가 남아 있으면 횟수를 증가시키고 숫자 판정 |
| `12`, `1234` | 세 자리 입력 안내 |
| `102` | 1~9 범위 안내 |
| `112` | 중복 숫자 안내 |
| `1a2`, `a12`, `12a` | 숫자만 입력하도록 안내 |
| `안녕하세요`, `abc` | 일반 채팅 |

오류 안내는 기회가 남아 있는 입력자에게만 표시하고, 입력 원문은 채팅으로 모두에게 전달합니다. 기회를 모두 쓴 뒤에는 올바른 형식의 숫자 추측을 막으며, 일반 채팅은 계속 사용할 수 있습니다.

문자와 숫자가 섞인 입력은 세 글자일 때만 검사합니다. `방가2`처럼 채팅 의도로 입력한 경우에도 숫자 입력 안내가 나오며, `a1`이나 `123a`는 일반 채팅으로 처리됩니다.
